# Contributing to UniFind

Thank you for your interest in improving UniFind.

## Development Workflow

1. Fork the repository and create a new branch from `main`:
   ```bash
   git checkout -b feat/your-feature-name
   ```
2. Install dependencies and run the test suite:
   ```bash
   npm install
   npm test
   ```
3. Verify TypeScript compilation and the production build before committing:
   ```bash
   npm run build
   ```
4. Open a Pull Request describing the problem your change solves and how you tested it.
